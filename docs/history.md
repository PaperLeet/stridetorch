# Original development records

This repository was extracted from the public `packages/stridetorch/` tree at
[PaperLeet core 17d6e1ef560ea0da4dd941939bb1415305ea4004](https://github.com/PaperLeet/paperleet.github.io/commit/17d6e1ef560ea0da4dd941939bb1415305ea4004).

The extraction preserves authors, commit messages and dates for the selected
runtime paths and their validation records. Path filtering necessarily changes
commit hashes. `original-commit-map.txt` records the original and extracted
hashes; an all-zero target means a commit did not contribute retained content.
Earlier library names and unselected history remain in the original repository.

Original PR conversations, approvals, checks and comments stay at
[PaperLeet development pull requests](https://github.com/PaperLeet/paperleet.github.io/pulls?q=is%3Apr).
They are not recreated as new reviews in this repository. The original public
repository remains reachable as its role changes to deployment.

The extracted source, tests, license and notices match that source snapshot.
Standalone packaging, CI and documentation were then adjusted here. Historical
`.tar.gz` and `.tar.xz` benchmark bundles were excluded from this checkout; links
to the original immutable public snapshot preserve access to them.
